9. FINAL CONCLUSION DATA
============================================================

If the matrix shows:
  44100 / 48000 / 88200 / 96000 / 176400 / 192000
with exact actual rates,
then the LEGACY HDA PCM exposes the complete 44.1–192 kHz range.

If S32_LE works at 192000:
  -> 32-bit CONTAINER/transport is accepted.
  -> This does NOT prove a 32-bit analog DAC.

If S24_LE also works:
  -> 24-bit PCM is directly accepted.

If S24_3LE works:
  -> packed 24-bit PCM is directly accepted.

IMPORTANT:
This tests digital hardware/driver PCM negotiation.
It does NOT measure analog DAC SINAD, THD+N, noise,
dynamic range, output power, or the true number of
physical DAC bits. Those require an external ADC/audio analyzer.
